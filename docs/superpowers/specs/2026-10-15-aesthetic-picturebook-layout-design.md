# 绘本图文融合与审美排版设计规格

**日期：** 2026-10-15  
**状态：** 已确认，待实现
**适用版本：** `make-kids-picturebooks` 当前 `schema_version: 1` 体系  
**问题来源：** 实际试用中发现插画与字幕视觉脱离、排版缺少审美和页面节奏；同时需要让成品适应小红书和抖音的竖屏阅读场景。

## 1. 目标

把当前“图片层 + 可提取文字层”的技术实现，升级为“技术分层、视觉融合”的绘本排版流程，并在不破坏印刷版的前提下增加可验收的社媒竖屏输出。

完成后，Skill 应能够在生成插画之前为每页确定：文字进入画面的自然空间、文字与人物和视觉焦点的关系、排版模式、文字层级和本页的视觉节奏；生成后检查可确定的版面错误，并要求人工或模型复核不可由脚本判断的审美结果。

## 2. 非目标

- 不把中文正文直接烘焙进插画；
- 不用脚本自动判断“这张图是否真正好看”；
- 不用一个固定模板强行套用所有页面；
- 不重做故事、角色生成或 PDF 拼版的全部架构；
- 不把实物打印反馈伪装成数字检查结果；
- 不把某个平台当前的界面遮挡规则当成永久不变的承诺；第一版只定义可配置的通用竖屏安全区；
- 不改变现有 `schema_version: 1` 的基础兼容性。

文字继续作为可编辑、可提取和可嵌入字体的 PDF 文字层存在；变化的是文字区域的设计、文字卡样式、图文关系、社媒画布和验收流程。

## 3. 现状与根因

当前实现已有 `text_area`/`text_box_mm`、背景图文重叠规则、字体与溢出检查，以及 `text_area_reviewed` 门槛。但仍有四个断点：

1. 版式计划没有成为结构化必填输入，图像提示词、逐页清单和版式容易脱节。
2. 渲染器只知道文字框坐标，不知道文字框的视觉角色和样式。
3. 文字卡、叙事带、颜色、透明度、圆角和对齐没有统一数据契约。
4. 验收主要检查溢出、尺寸、字体和文件存在，不能区分“图文融合”和“图片下面贴字幕”。

根因是缺少一个明确的 **page layout design pass（逐页版式设计阶段）**。

## 4. 方案比较

### 方案 A：只增强提示词和文档

改动小，但没有结构化数据、渲染样式和可执行检查，无法稳定解决当前问题。不采用。

### 方案 B：结构化逐页版式设计 + 三种排版模式 + 审美复核

在插画生成前增加逐页 `layout_design`，定义文字区域、视觉焦点、避让对象、版式模式和文字处理方式；导出脚本根据模式绘制文字层和可选文字卡；验收增加版式契约和逐页审美审核记录。

这是当前 Skill 最合适的方案：改动可控，能连接分镜、提示词、插画和 PDF，同时保留人工审美复核。不把审美判断伪装成自动化证明。

### 方案 C：全自动视觉排版引擎

通过视觉模型自动检测脸部、道具、纹理、焦点和文字安全区，再自动寻找最优位置。暂不采用，作为后续实验方向，因为模型版本、成本、不可复现性和误判风险尚未被质量门覆盖。

## 5. 选定设计

### 5.1 逐页 `layout_design` 契约

每个成书页面增加以下对象；规划阶段允许 `pending`，数字验收阶段必须完整并通过：

```json
{
  "layout_style_version": "layout-v1",
  "layout_mode": "scene-integrated",
  "text_anchor": "top-left",
  "text_treatment": "natural-space",
  "text_align": "left",
  "max_lines": 4,
  "focal_point": "孩子手中的纸飞机",
  "text_safe_area": "左上方浅色墙面",
  "avoid_covering": ["人物脸部", "手部动作", "纸飞机"],
  "page_rhythm": "action",
  "palette_token": "warm-paper",
  "status": "pending",
  "social_layout": {
    "profile": "social-vertical-9x16",
    "canvas": {"width_px": 1080, "height_px": 1920},
    "subject_safe_area": [0.08, 0.10, 0.84, 0.72],
    "text_safe_area": [0.08, 0.76, 0.84, 0.14],
    "avoid_regions": ["top-ui", "bottom-ui"],
    "source_aspect_ratio": "9:16",
    "status": "pending"
  }
}
```

字段约束：

- `layout_style_version`：本册统一的版式系统版本。
- `layout_mode`：`scene-integrated`、`soft-card`、`narrative-band` 三选一。
- `text_anchor`：`top-left`、`top-right`、`bottom-left`、`bottom-right`、`left`、`right`、`center` 之一。
- `text_treatment`：`natural-space`、`soft-card`、`narrative-band`，必须与 `layout_mode` 对应。
- `text_align`：默认 `left`；仅在样页确认后允许 `center`。
- `max_lines`：正整数，用于规划和文字密度检查。
- `focal_point`：必须是具体画面对象或动作，不能只写“主体”。
- `text_safe_area`：必须说明文字所在的实际画面区域。
- `avoid_covering`：列出脸、手、知识关键物等不能被遮挡的对象；无对象时使用空数组并说明原因。
- `page_rhythm`：`establishing`、`action`、`pause`、`turn`、`resolution` 之一。
- `palette_token`：使用本册风格卡批准的颜色令牌，不在逐页临时换色。
- `status`：`pending`、`passed`、`failed`。
- `social_layout`：社媒竖屏变体；第一版固定支持 `social-vertical-9x16`，坐标使用相对画布的 `[x, y, width, height]`，范围为 `0..1`。
- `subject_safe_area`：人物、脸部、手、关键动作和知识要点应保持在此区域内；`text_safe_area`：字幕和文字卡的设计区域。
- `source_aspect_ratio`：社媒源图必须按声明的比例生成；禁止把印刷横向/页面图未经审查直接强裁成竖屏。

`page-manifest.json` 作为逐页计划的来源记录，`layout.json` 保存排版执行副本。数字验收时，二者的 `layout_design`、`text_area` 和正文必须一致。

### 5.2 三种排版模式

#### `scene-integrated`：自然留白型

适用于墙面、天空、地面、桌面等低纹理区域：不绘制明显字幕框，文字进入确认过的自然留白，画面延展到文字周围，颜色使用本册批准的文字令牌。

#### `soft-card`：柔和文字卡型

适用于背景复杂但仍需保持场景连续性的页面：使用圆角、低对比边界和批准的纸张色；透明度固定在版式系统范围内；文字卡不能覆盖脸、手、知识关键物和视觉焦点；不使用普通软件默认白色矩形。

#### `narrative-band`：场景叙事带型

适用于动作复杂、没有足够自然留白的页面：在页面下方或侧面设计连续叙事区域，保持统一颜色、边距、圆角和字体层级；不挤压正文至小字号；位置变化必须有页面节奏理由。

### 5.3 插画生成前的版式锁定

正式生成每页插画前必须完成：故事正文和分页确认、`layout_design`、`text_box_mm` 初始区域、人物/道具/知识关键物/视觉焦点位置，以及图像提示词中的文字安全区说明。

图像提示词必须说明完整纵向单页、不生成文字或伪文字、文字安全区的位置和纹理、预留行数，以及人物脸、手、道具和知识关键物的避让要求。生成后必须查看实际图像；留白消失或视觉焦点改变时，回到插画修订，不直接把字幕压到复杂背景上。

### 5.4 PDF 渲染行为

`render_book.py` 保持图片和文字分层，但增加：

- `text_treatment` 对应的自然留白、柔和文字卡和叙事带绘制；
- 文字卡的圆角、内边距、颜色和透明度；
- 文字对齐和行高的统一处理；
- 每页 `max_lines` 与实际排版行数检查；
- 输出报告中的版式模式、文字区域和样式摘要。

渲染器不负责判断人物脸部或道具是否被遮挡，这部分继续由逐页视觉审核负责。

### 5.5 社媒竖屏输出

社媒输出与印刷输出使用同一故事正文和角色设定，但拥有独立的竖屏画布与安全区。第一版固定提供 `social-vertical-9x16`：

- 目标画布为 `1080×1920`，作为小红书和抖音竖屏阅读的共同基础输出；后续可以新增 `social-note-3x4`，不改变现有 9:16 契约；
- 插画提示词必须在生成前声明 `9:16 portrait composition`、主体安全区、字幕安全区、顶部/底部避让区和不可裁切的关键对象；
- 源图必须按竖屏比例生成，渲染器不得默认把印刷页中心强裁成竖屏；比例不符时应拒绝导出，除非清单明确记录经过审核的适配方式；
- 社媒导出使用逐页 PNG/JPEG，字幕可以栅格化以适应平台阅读，但印刷 PDF 仍必须保留可提取、可嵌入字体的文字层；
- 社媒版验收至少检查画布尺寸、源图比例、主体/文字安全区、字幕溢出、关键对象避让和页间连续性；脚本只能证明几何和文件条件，不能单独证明审美完成。

### 5.6 审美审核记录

逐页阅读审核记录增加结构化版式审核：

```json
{
  "layout_review": {
    "status": "passed",
    "evidence": "正文位于左上方浅色墙面，未遮挡两名儿童的脸和纸飞机；文字卡与本册暖纸色一致。",
    "text_image_relationship": "integrated",
    "contrast": "passed",
    "focal_point_clear": true,
    "occlusion": "none",
    "rhythm_reason": "动作页使用右下人物、左上文字，承接上一页的视线方向。"
  }
}
```

脚本只验证字段完整、枚举合法、证据非空、版式副本一致和文字可测条件；不把这些字段当成自动审美证明。`layout_review` 缺失或未通过时，不得进入 `digital_checked`。

## 6. 文件和模块变更范围

预计修改：

- `SKILL.md`：增加版式设计阶段和暂停条件；
- `references/composition.md`：补充三种模式、版式锁定和提示词契约；
- `references/art-direction.md`：补充整册文字样式、颜色令牌和页面节奏；
- `references/printing.md`、`references/acceptance.md`：补充文字卡、叙事带和审核门槛；
- `scripts/render_social.py`：按 `social-vertical-9x16` 输出逐页竖屏图并执行安全区和比例检查；
- `references/social-output.md`：说明竖屏构图、通用安全区、提示词锁定和平台适配边界；
- `assets/book-template.json`、`assets/page-manifest-template.json`：提供可执行的版式示例；
- `scripts/render_book.py`：实现三种文字处理方式和版式摘要；
- `scripts/validate_page_manifest.py`、`scripts/accept_book.py`：校验版式契约、副本和审核记录；
- `tests/`、`evals/`：增加版式验证、渲染、验收和行为场景。

不修改来源读取、年龄筛选、字体嵌入和 PDF 拼版主架构。

## 7. 测试设计

### 单元和契约测试

- 缺少 `layout_design` 时，规划模式允许，完成模式拒绝；
- 非法模式、锚点、文字处理方式、节奏或行数被拒绝；
- `soft-card` 缺少颜色令牌或面板参数时被拒绝；
- 背景文字重叠必须有 `text_area_reviewed: true`；
- 实际行数超过 `max_lines` 时导出失败；
- 版面副本与逐页清单不一致时验收失败；
- `layout_review` 缺失、失败或证据为空时不能进入数字完成状态；
- 三种模式都能生成可提取文字、嵌入字体且不破坏现有 PDF 尺寸门槛。
- 社媒竖屏导出固定为 `1080×1920`，源图比例不符、字幕越界或主体落入避让区时失败。

### 回归测试

现有自然背景页、普通 inset 重叠拒绝、封面/封底、无字页和四页倍数规则必须继续通过；全量测试不得回退。

### 行为评测

新增“自然留白”“复杂背景文字卡”“社媒 9:16 构图”“一次生成整本时暂停”“好看不能作为验收证据”“跳过视觉检查不能宣称通过”等场景。

## 8. 迁移和兼容

- 保持 `schema_version: 1`，新增字段采用可识别的附加对象；
- 旧版布局可以读取和重新导出，但缺少 `layout_design` 或 `layout_review` 时只能保持 `laid_out`，不能直接升级为 `digital_checked`；
- 提供旧页迁移提示，要求补充版式模式、文字安全区、视觉焦点和逐页审核；
- 新版包版本至少提升到 `0.10.0-preview` 或下一明确迭代版本，并同步 README、RELEASE、CI 和 ZIP 文件名。

## 9. 完成验收标准

1. 至少一个真实 4 页或 8 页样册使用至少两种版式模式。
2. 每个故事页都有结构化 `layout_design`。
3. 图片提示词包含文字安全区和避让对象。
4. PDF 文字可提取、字体可嵌入，原有尺寸和打印质量门不退化。
5. 文字卡和叙事带在阅读版和打印版中不越界、不溢出、不遮挡关键内容。
6. 至少一份真实样册可以输出 `1080×1920` 社媒竖屏页，且通过尺寸、比例、安全区和字幕溢出检查。
7. 页面之间的文字位置和样式连续，同时存在有理由的节奏变化。
8. 每页都有具体 `layout_review` 证据，不能使用“已检查”“效果良好”等空泛语句。
9. 全量测试、快速 Skill 校验和行为评测通过。
10. 至少一份阅读版和打印版经过人工逐页查看；没有实际试打时明确标记为待验证。
