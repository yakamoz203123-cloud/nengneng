# 小红书 3:4 图文排版修正计划

## 目标

把小红书静态图文从当前的 9:16 默认模式改为独立的 `xiaohongshu-feed-3x4`（1080×1440）模式，保留抖音/长屏使用的 `social-vertical-9x16`（1080×1920），避免横向插画被塞进竖屏后产生大面积无意义留白。

## 约束

- `schema_version` 继续为 1。
- 旧的显式 `social-vertical-9x16` 项目仍可读取和导出。
- 不把 9:16 页面伪装成小红书 3:4，也不把印刷页默认中心裁切成社媒页。
- 小红书模式必须原生使用 3:4 源图；抖音模式必须原生使用 9:16 源图。
- 图文仍保持技术分层、文字可读；最终审美仍需要人工/模型视觉复核。

## 任务

1. 先增加 profile-aware 的失败测试：3:4 画布、3:4 源图、默认 profile、错误比例拒绝、两个 profile 的安全区校验。
2. 实现 profile 注册表和渲染器/验收器按 profile 取画布与比例，不复制硬编码分支。
3. 更新模板、参考规则、Skill 主流程、验收文档和回归夹具；明确小红书默认 3:4、抖音单独 9:16。
4. 运行聚焦测试、全量测试、编译/差异检查和真实夹具导出；人工检查新 3:4 页面不再出现顶部横幅加大块空白。

## 验收

- `render_social_page()` 默认输出 1080×1440 的小红书页。
- 显式传入 `profile="social-vertical-9x16"` 仍输出 1080×1920。
- 两个 profile 都拒绝错误源图比例。
- 模板和 Skill 文档不再把 9:16 写成小红书默认比例。
- 全量测试无回归。
