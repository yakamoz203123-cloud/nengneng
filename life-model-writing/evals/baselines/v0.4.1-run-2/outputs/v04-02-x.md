# 平均收入一样，为什么面对同一笔支出，选择却不同

月底要交一笔七千元的支出。小周看了一眼工资到账日，照常付款；小林却先打开账单，又看了看下个月的收入，最后选择分两次付。两个人放在两年的账本里，平均每月收入可能一样，但那七千元落在哪一天、哪一个月，带来的感受完全不同。

平均收入是把一段时间里的总收入摊平后的数字，它适合概括一段时期，却不等于每个月钱包里都有同样多的钱。为了看清差别，可以用一个纯粹的假设：小周每个月稳定拿到一万元；小林两个月分别拿到六千元和一万四千元。两个月合计都是两万元，平均每月都是一万元。可是，如果七千元的支出刚好落在小林拿六千元的那个月，他当月就会出现一千元的缺口；小周则还剩三千元缓冲。

这时影响选择的，不只是“收入够不够”，还包括收入什么时候到账、支出什么时候扣走，以及手上有没有可以马上动用的存款。稳定收入的人，面对同一笔钱，更容易选择一次性付款、签下较长的服务周期，或者把预算安排得更远。收入波动的人，可能更看重分期、延期和保留现金，因为一次性支出会把下个月的风险提前推到今天。

波动还会改变人对风险的感受。平均数把高收入月份和低收入月份揉成一条线，却遮住了最难受的那几个月。只要某个月收入低于固定支出，平均数再漂亮，也不能直接替这个月付款。对有房租、房贷、照护费用的人来说，现金流一断，损失可能不是少买一件东西，而是产生滞纳金、借款成本，甚至被迫卖掉长期资产。

当然，这并不意味着收入不稳定的人一定更谨慎，也不意味着稳定收入的人一定敢花。存款、信用额度、家庭支持、支出能否推迟，都会改变实际选择。小林如果提前攒下足够的缓冲金，面对七千元时也可能很从容；小周如果每月都有更高的固定负担，也可能比平均收入看起来更紧张。

所以，比较两个人的经济处境，不能只问“平均每月赚多少”。还要看收入的波动、到账时间、固定支出的刚性和可动用的缓冲。平均数回答的是一段时期大概有多少资源；真正决定某个月敢不敢付、能不能等的，常常是资源何时到手，以及最差的那段时间能不能撑过去。
