# v0.4.2 理论必要性分层 A/B 测试报告

日期：2026-10-11
运行目录：`evals/runs/v0.4.2-theory-necessity-run-1`
评测集：`evals/v0.4.2-theory-necessity-cases.json`

## 1. 测试目的

上一轮未见主题泛化测试中，Skill 平均 29.5、普通组 27.6，优势 +1.9，刚好低于预设 +2.0 门槛。本轮进一步控制题面：每个 X/Y 配对的用户输入逐字相同，只改变是否加载 Skill；同时把题目分为低、中、高三种理论必要性，检验 Skill 的增益是否依赖题目难度。

本轮共 12 个主题、24 份文案：

- 低层：默认选项、收银台顺手购买、具体提醒、钥匙固定位置。
- 中层：优惠券使用率、不同群通知、共享办公、截止日期返工。
- 高层：机场安检排队、教育政策平均效果、路灯与事故因果、停留时间与满意度指标。

## 2. 运行完整性

- 输出数量：24/24。
- 所有 X/Y 题面对逐字一致。
- 模型配置：GPT-5；记录的调用方式为同通道配对生成。
- 生成上下文：X 不加载 Skill；Y 加载当前 Skill 和相关参考规则。
- 长度：24/24 通过 800–1200 非空白字符。

- 独立盲评：24/24 评分文件有效，`independent=true`，总分自洽。
- Critical error：Skill 组 0，普通组 0。

限制：本轮使用两个独立生成代理线程，继承同一模型和调用通道，但没有固定随机种子，不能等同于完全相同采样轨迹的严格实验。它比上一轮的混合来源测试更接近 A/B，但仍应被称为受控流程对照，而不是统计学意义上的单变量实验。

## 5. 第一性原理解释

本轮结果不能简单解释为“Skill 没用”。它支持更具体的判断：

1. Skill 的规则能维持高质量、边界清楚和不强行堆砌理论；低层 4 组全部平局，说明没有明显把简单问题写坏。
2. 普通模型本身已经能处理许多生活现象，新增流程不一定带来可见分差；高层题目中普通组平均 29.75，说明题面仍不足以形成真正困难的推理压力。
3. 当前评分量表存在天花板效应。普通文案达到 29–30 后，即使 Skill 在变量、反事实或边界上更稳定，也很难再转换成两分以上的总分差。
4. 如果产品主张是“比普通模型更可靠”，不能只看平均分，还要增加对错误类型、理论装饰、因果越界和反事实预测的单独计数。

## 6. 结论

本轮严格 A/B 没有通过增量优势门禁。当前证据可以支持：Skill 是一个能稳定组织理论、边界和口播结构的写作流程；当前证据不能支持：在同一模型面对同一新题时，Skill 普遍能把质量提高至少 2 分。

本轮不建立 v0.4.2 通过基线，不降低门禁，不覆盖 v0.3 正式回归基线，也不撤销 v0.4.1 已见题候选结果。保留四个分层 run 作为可复核失败证据。

## 7. 最小下一步

下一轮不再继续扩大题库，而是把评分从总分差转向“错误增量”：预注册理论装饰率、因果越界率、反事实缺失率、物理假设遗漏率和边界遗漏率，并加入需要真实信息不足时明确拒绝确定性结论的压力题。只有当 Skill 在这些可观察错误上显著低于普通组，才有理由说它提供了普通大模型之外的稳定能力。
