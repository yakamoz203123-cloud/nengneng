# v0.4 候选题库第一轮盲测报告

## 结论

本轮不晋升为 v0.4 正式基线，也不替换 v0.3。原因不是硬检查或关键理论错误，而是 Skill 条件平均分为 27.9/30，低于既定门槛 28.0/30。

## 可复核结果

- 评测 run：`evals/runs/v0.4-run-1/`
- 匿名稿件：20 篇，10 组配对
- 长度与内部泄漏：20/20 通过
- 独立盲评：20 个评分文件，均 `independent=true`
- critical errors：0
- Skill 条件平均：27.9/30
- 普通条件平均：24.0/30
- 平均优势：+3.9
- Skill 胜出：10/10
- Skill 最低单篇：27/30
- Skill 六维平均：理论选择 5.0、因果推理 5.0、跨学科整合 4.2、口播自然度 4.0、内容完整性 5.0、事实准确与边界 4.7
- 唯一失败门槛：`min_skill_average_total`

## 主要观察

1. Skill 的稳定优势已经出现：每组都胜出，尤其在理论拆分、反事实、物理/数字自洽和因果边界方面明显优于普通条件。
2. 平均分没有达到发布门槛，说明“稳定胜出”还不等于“整体达到正式基线质量”。
3. 主要扣分集中在口播自然度和跨学科整合的呈现方式：Skill 稿常出现“第一种机制/第二种机制”、变量列表和术语密度偏高的问题。
4. 个别稿件存在小型边界风险：收入例子隐含初始现金缓冲，蒸发机制被简化为温差，非回应偏差与样本量的关系需要更严格表达；这些没有达到 critical error，但值得在下一轮修正。

## 下一轮最小动作

不扩大理论库，也不降低门槛。下一轮只针对两个问题做最小规则实验：

- 把“理论比较”压缩为服务因果链的两三句，避免把理论名称和变量清单写成讲义。
- 在数字和物理例子后增加一句最小假设说明，特别是分母/初始存量、湿度与蒸发、抽样误差与非回应偏差。

完成规则实验后，复用这 10 组 v0.4 题目进行新鲜上下文复测。若平均分达到 28.0、其他门槛不退化，才考虑建立正式 v0.4 基线；否则继续保留 v0.3 作为唯一发布门禁。
