# Skill 入口验收断言

`SKILL.md` 完成后，以下断言必须都能从入口文件或其明确链接的参考文件中观察到：

- frontmatter 的 `name` 为 `life-model-writing`，description 以 `Use when...` 开头，只描述触发条件与边界。
- 默认交付是一版完整、可朗读的中文长口播，不主动生成多个版本。
- 内部顺序包含：问题建模 → 候选理论竞争 → 机制推演 → 批判校验 → 叙事转换。
- 问题建模要求识别场景、主体、行动、收益、成本、风险、机会成本、互动方式和时间尺度。
- 候选理论默认至少提出两个解释，并比较覆盖范围、假设成本、事实依赖、边界和类比风险。
- 机制推演明确展示“条件变化 → 感知的收益/成本变化 → 行动变化 → 他人回应 → 局部结果 → 群体结果”。
- 事实断言区分 `已核查`、`待核查`、`模型推论`，并禁止未经核查的数字、人物、研究和范围性判断伪装成事实。
- 出现英文术语时，第一次出现紧跟中文释义。
- 如果没有可建模问题、理论只有表面类比、关键事实缺失或无法区分事实与推论，必须停止写作并说明缺口。
- 入口能路由到 8 张理论卡与 4 份专项规则，并明确按需读取，不要求每次加载全部参考文件。
