# 理论误用检查

理论名称只有在改变解释时才保留。发现以下问题时，优先删掉名词、补中间机制或降低结论强度。

| 误用类型 | 检查问题 | 修正方式 |
|---|---|---|
| 表面类比 | 两个场景是否只有词汇相似，收益、约束和行动结构却不同？ | 列出双方变量；无法对应就换模型。 |
| 变量偷换 | 理论中的“成本、收益、信号、连接”是否悄悄变成了别的概念？ | 给变量下定义，保持同一含义。 |
| 层级错位 | 个体层面的选择是否被直接写成群体或制度结果？ | 补上互动、扩散或聚合机制。 |
| 因果跳跃 | 观察到相关是否直接写成因果？ | 写出时间顺序、替代解释和所需证据。 |
| 结果倒推 | 因为结果像某理论，是否反过来宣称理论被证明？ | 把理论当作待检验解释，不把拟合外观当证据。 |
| 过度泛化 | “在某条件下”是否被写成“总是如此”？ | 写明场景、样本、时间和失效条件。 |
| 确定性伪装 | 条件性推论是否被写成必然预测？ | 使用条件句、概率词和不确定性标记。 |
| 单一理论霸权 | 是否忽略了更简单或更贴近事实的替代解释？ | 至少列出两个候选解释并比较假设成本。 |
| 机制缺失 | 是否只报出理论名字，没有说明变量如何变化？ | 使用完整因果链逐步推演。 |
| 事实污染 | 理论例子中的数字、人物、事件或研究是否未经核查？ | 标注 `待核查`，或改用无事实负担的假设例子。 |

## 最小审查顺序

1. 场景和理论的变量是否同构。
2. 理论是否真的改变了对行为的解释。
3. 个体、群体和制度层级之间是否有连接机制。
4. 结论是否依赖外部事实；若依赖，是否有直接来源。
5. 删除理论名称后，因果链是否仍然成立。

## 红线

如果理论不能改变解释，就删掉理论名词；如果关键事实未核查，就把结论降级为待核查假设；如果只能靠“本质上、归根结底”连接两步，就说明中间机制还没写出来。

## 跨学科连接检查

- 物理学中的存量、流量、容量、扩散或阈值可以帮助描述社会系统的结构和变化，但不能因为词形相似就把物理定律直接当作社会规律；必须说明社会主体的选择、制度约束或网络结构如何完成桥接。
- 联合两个理论时，写出连接变量（例如回应概率、可见性、等待成本或容量），并说明一个理论改变了另一个理论的哪个条件。若删除其中一个理论后解释完全不变，删掉装饰性理论。
- 联合模型至少给出一个可观察的条件性预测，并指出该预测需要哪些事实或实验才能检验；不要把均衡、阈值或系统状态写成现实中必然发生的结果。
